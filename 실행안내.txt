ROUTER 앱 소스

이 ZIP은 설치용 APK/EXE가 아니라 웹앱 소스입니다.
지도 화면, 경로 계산 코드, 수집한 OSM 지도 데이터가 포함되어 있습니다.

로컬 실행 안내
1. ZIP 압축을 풀고 Node.js와 Bun을 설치합니다.
2. 압축을 푼 폴더에서 터미널을 엽니다.
3. bun install
4. bun run dev
5. 터미널에 표시된 로컬 주소를 브라우저로 엽니다.

패키지 설치 및 로컬 실행은 이 전달본에서 별도로 검증하지 않았습니다.
배경지도는 인터넷 연결이 필요합니다.
경로의 지붕 정보는 OSM 태그 기준이며 현장 검증 자료가 아닙니다.
